# S3-demo - AWS Application Load Balancer Project

## Project Overview
3 EC2 instances ah create panni, Application Load Balancer (ALB) use panni traffic ah distribute panna project.

## Steps Done
1. Created 3 EC2 Instances in ap-southeast-2 (Sydney) region
2. Installed Apache (httpd) in all 3 instances
3. Created Target Group - S3-tag
4. Created Application Load Balancer - S3-alb
5. Load Balancing verified - Refresh panna vera vera server varum

## Tech Used
- AWS EC2, AWS ALB, Target Group, Security Group, Apache
